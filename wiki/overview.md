# 🧭 Overview

Síntesis de alto nivel de quién es Juanfra y en qué está trabajando, para orientarse rápido sin tener que recorrer todo `wiki/`. Ver [[index]] para el catálogo completo y [[conventions]] para las reglas de la bóveda.

## Quién es

Juan Fra es autónomo en Sabadell (Catalonia). Combina tres frentes: desarrollo de software, marketing de afiliación, y trabajo profesional como fotógrafo/videógrafo de bodas. Detalle completo en [[perfil-juanfra]].

## Proyectos activos

- **[[vera-crm|Vera CRM]]** — SaaS propio, CRM para fotógrafos/videógrafos de boda. Co-desarrollado con [[alba-escalante-escorihuela|Alba]].
- **[[organizador-fotos-duplicity|DUPLICITY]]** — app de escritorio para organizar y deduplicar fotos/vídeos.
- **[[rawpress|RAWPress]]** — compresión lossless de RAWs de Sony + actualización de catálogos Lightroom.
- **[[alba-salud|Alba Salud]]** — app de salud y nutrición a medida para Alba.
- **[[nexus-media-lab|Nexus Media Lab]]** — bot de Amazon Afiliados (Chollos Verificados) + web de agencia de fotografía/vídeo corporativo.
- **[[dossier-video-bodas|Dossier de vídeo]]** — material de ventas para Juan Fra Palos · Photo & Film.

Cada proyecto tiene además un registro de trabajo sincronizado desde Claude Code en `wiki/entities/proyectos/claude-code/` (ver [[Claude-Code]]).
